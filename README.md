# DevTools Mobile Browser (Android)

A lightweight Native Android Browser with built-in **Mobile DevTools (Eruda)**.

## Features
- **In-App DevTools**: Inspect Elements, View Console Logs, Network requests, Cookies & Storage.
- **Top Navigation Bar**: URL bar, Back, Forward, Refresh & DevTools toggle button.
- **Remote Debugging**: Support `chrome://inspect` via USB.
- **Automated GH Build**: Automatically builds APK on GitHub Actions.

## How to Build via GitHub
1. Push this repository to GitHub.
2. Go to the **Actions** tab on your GitHub repository.
3. Once the workflow finishes, download the `DevTools-Browser-Debug-APK` artifact!
